# Contributing to Fabian's Projects

Thank you for your interest in contributing! 

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Make your changes** in a clear, scoped manner.
3. **Run the checks** locally before committing:
   - `npm install`
   - `npm run check` (runs linting, formatting, and tests)
4. **Commit your changes** with descriptive commit messages.
5. **Submit a Pull Request** to the `main` branch.

## Guidelines

- **Small is better:** Prefer small, focused PRs over large, sweeping changes.
- **Testing:** Ensure that any new features or bug fixes are accompanied by relevant tests in the `tests/` directory.
- **Code Style:** Follow the existing ESLint and Prettier configurations.
- **Localization:** If you add text to `app.js`, please provide both English (EN) and Romanian (RO) translations.
